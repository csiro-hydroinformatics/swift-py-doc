# Package overview

**swift2** is a Python package for ensemble streamflow forecasting and semi-distributed hydrologic modeling. It enables water resource managers and researchers to simulate catchment hydrology, calibrate model parameters against observed data, and generate probabilistic forecasts. The package supports both traditional deterministic simulations and ensemble-based approaches that account for uncertainty in meteorological inputs and model structure.

At its core, **swift2** provides lumped and semi-distributed rainfall-runoff models (such as GR4J, GR5H) that can be configured as individual subcatchments or connected into dendritic networks representing entire river systems. The framework handles the spatial routing of water through channel networks, allows for reservoir operations, and supports error correction models like ERRIS to improve forecast accuracy. Users can work with various time steps (hourly, daily, monthly) and easily swap between different model structures.

A typical workflow involves creating a `Simulation` object that represents your catchment model, then using `Parameteriser` objects to define the parameter space you want to explore. For calibration, you create an `ObjectiveEvaluator` that compares simulated outputs against observations using statistics like NSE or RMSE, then pass this to an `Optimiser` (typically SCE-UA) to find optimal parameter values. Once calibrated, you can run deterministic simulations or set up `EnsembleSimulation` objects for probabilistic forecasting with multiple input scenarios.

The package is designed around a small set of core classes that work together: `Simulation` manages model execution and state, `HypercubeParameteriser` and its subclasses handle parameter definitions and transformations, `ObjectiveEvaluator` calculates goodness-of-fit metrics, and `Optimiser` performs parameter estimation. Time series data flows in and out through methods like `play_input()` and `get_recorded()`, with support for both simple NumPy/xarray structures and more complex ensemble forecast formats. Most operations return standard Python types (DataFrames, dictionaries, xarray DataArrays) making it straightforward to integrate swift2 into existing analysis pipelines.
